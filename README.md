## Features

### Timer Application
A fully functional timer web application with an intuitive user interface.

**Features:**
- ⏱️ Set custom minutes and seconds
- ▶️ Start, Pause, and Reset controls
- 🔔 Audio notification when timer finishes
- 💅 Modern, responsive design with gradient background
- ⌨️ Clean and user-friendly interface

**How to use:**
1. Open `timer.html` in your web browser
2. Enter desired minutes and seconds
3. Click "Start" to begin the timer
4. Use "Pause" to temporarily stop the timer
5. Click "Reset" to clear and start over
6. A notification sound plays when the timer completes

**Files:**
- `timer.html` - Complete timer application (HTML, CSS, JavaScript)
